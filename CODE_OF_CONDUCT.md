# Code of Conduct

SpoofGuard follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
kept deliberately short.

**The rule:** be straight, be civil, argue the code — not the person. Good-faith
disagreement is welcome and expected. Harassment, personal attacks, or
bad-faith conduct are not.

**Scope:** applies in the issue tracker, pull requests, discussions, and any
project space.

**Enforcement:** a warning, then a ban, at the maintainer's discretion. Report
conduct concerns privately via the contact in [SECURITY.md](./SECURITY.md) —
they will be handled discreetly and in good faith.
